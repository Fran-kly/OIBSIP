# House Price Prediction Using Linear Regression

## Objective

Build and evaluate a Linear Regression model for predicting house prices using property-related features.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Tasks Performed

- Exploratory Data Analysis
- Null value and descriptive statistics checks
- Feature selection
- Categorical feature encoding
- Correlation analysis
- 80/20 train-test split
- Linear Regression model training
- Model evaluation using MSE, RMSE, and R²
- Actual vs predicted price visualisation
- Residual analysis
- Coefficient analysis
- Ridge Regression comparison

## Model Result

The Linear Regression model achieved an R² score of approximately 0.653.
