# Data Cleaning Project

## Objective

Clean and prepare a retail sales dataset for analysis by handling missing values, duplicates, inconsistent formatting, outliers, and incorrect data types.

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Tasks Performed

- Data quality inspection
- Missing value handling
- Duplicate removal
- Data standardisation
- Outlier detection using IQR
- Data type correction
- Before vs after comparison
- Exported cleaned dataset

## Files

- `retail store sales.ipynb`
- `retail_store_sales.csv`
- `retail_store_sales_cleaned.csv`
