# Exploratory Data Analysis on Retail Sales Data

## Objective

Perform exploratory data analysis on retail sales data to identify sales trends, customer behaviour, product performance, and useful business insights.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed

- Dataset inspection
- Null value and data type checks
- Descriptive statistics
- Monthly and quarterly sales trend analysis
- Customer age and gender analysis
- Product category analysis
- Correlation heatmap
- Additional visualisation
- Business observations and recommendations

## Files

- `retail sales eda.ipynb`
- Retail sales dataset CSV
